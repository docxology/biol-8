# BIOL-8 repository maintenance

Use the [documentation index](docs/README.md) to locate teaching materials,
source formats, and the flat distribution directory. Preserve the numbering
used to match course artifacts. When changing an instructional item, update
the provided PDF and DOCX versions where those formats exist and check them
against its source.

The [course-resource manuscript](docs/manuscript/README.md) derives its counts
from the committed Git tree. It can be rebuilt without opening course payloads.
