# BIOL-8 — documentation

Course materials for **BIOL-8, Human Anatomy and Physiology** at College of
the Redwoods (Spring 2026). Fifteen modules from exploring life science
through the respiratory system (module table in the root `README.md`).

## Repository map

| Path | Contents |
|---|---|
| `course/` | Markdown source for all course content |
| `slides/`, `labs/`, `homework/`, `practice_tests/`, `module_keys/` | Rendered teaching artifacts by type |
| `dashboards/` | Interactive review dashboards |
| `ALL_FILES/` | Combined materials listing |

## How to work here

The root `README.md` is the entry point; it documents each module and where
its artifacts live. Materials are provided both as Markdown source
(`course/`) and rendered PDF/DOCX so they can be used as-is or rebuilt.
