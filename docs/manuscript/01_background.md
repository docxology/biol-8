# Background

The Spring offering has a syllabus and a schedule with course modules, labs,
and assessments. Resource directories group items by their role, while the
distribution directory brings the deliverable files together for reuse.
[Course repository](https://github.com/docxology/biol-8)

A Git blob identifies file content independently of its path. Two paths using
the same blob therefore represent the same committed bytes. The inventory
uses that relationship to match copies without loading their content
[@git-tree].
