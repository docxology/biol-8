# Agent guide — biol-8 `ALL_FILES/`

## Role

Flat mirror of every course material — Markdown, PDF, DOCX, and dashboard HTML
in a single directory — for bulk download into an LMS. The by-type directories
at the repository root (`course/`, `slides/`, `labs/`, `homework/`,
`practice_tests/`, `module_keys/`, `dashboards/`) hold the same files and are
where edits belong.
